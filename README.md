# Y2k FaShion

A single-file, self-contained Y2K fashion nostalgia site — pastel Y2K aesthetic with a one-click toggle into a darker gothic lolita color scheme.

Open `y2k-fashion.html` directly in a browser — no build step, no dependencies.

## Features

- **Lookbook** — illustrated polaroid outfit formulas
- **The Uniform** — a grid of iconic Y2K wardrobe staples
- **Shop the Look** — playful product cards with an "Add to Bag" interaction
- **Dress-Up** — an interactive chibi doll you can restyle piece by piece
- **Sticker Moodboard** — drag-and-drop stickers onto a corkboard, saved to your browser
- **Friendship Bracelet Maker** — click beads to string your own bracelet, saved to your browser
- **The Meme Page** — a *Mean Girls*-flavored sticky-note tribute
- **The Zine** — scrapbook-style diary snippets
- **Horoscope Generator** — pick a sign, get a randomized Y2K-teen-mag fortune
- **Gothic toggle** — a butterfly button that flips the entire site into a gothic lolita palette
- Animated sparkle canvas, floating petals, and a heart button with a burst animation

Built with plain HTML, CSS custom properties, and vanilla JS.
